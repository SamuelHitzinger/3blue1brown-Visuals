# Peptide torsion: production pipeline demonstration

## Request and scope

The user requested a small, visually focused demonstration generated through the
actual pipeline using custom scene instructions and the expanded authoring guides.
This run tests real lesson planning, editorial review, subtitle timing, scene
generation, validation and native visual review. It uses Astra with high reasoning.
No hand-authored replacement scene or seeded lesson is permitted.

The chosen example is one local torsion in an original idealized six-residue
peptide. It is a schematic geometric explanation, not deposited coordinates,
folding prediction or a dynamics simulation. Target length is approximately
16–22 seconds; production subtitle reading time determines the exact duration.
Delivery is silent, with optional subtitle tracks outside the visual construction.

## Visual contract

The approved component and derivative images in the user's explanation-style
skill were inspected. Transfer their persistent objects, local notation, quiet
scaffold and visible operation. The rejected chart-template image supplies the
counterexample: no permanent title/chart/footer layout.

The molecular construction owns the frame. Use one common fixed coordinate frame,
an oblique stationary camera, thin bonds, modest atoms and room for the entire sweep.
Retain upstream geometry in neutral/muted blue, the selected middle N–CA axis in
teal and the moving downstream portion in a warm accent. These colors identify
roles, not chemical elements. Keep a quiet initial reference for comparison.

Change exactly one middle phi angle, keeping other torsions fixed. Show how local
rotation carries downstream atoms while preserving the axis and bond lengths.
Tie a small phi label to the actual hinge and a trace to one actual downstream atom.
Use setup and result holds. Do not recenter each pose, move the camera during the
operation, add decorative axes, hide the operation behind a surface or replace
geometry with captions.

## Verification

Save request, model settings, effective prompts, generated source, reviews and
hashes. First inspect a 3–8 second motion proof, including an interior transformation
and hold, then export the full source unchanged. An independent reviewer compares
actual native frames/decoded video samples with the baseline. Reasoning, readability,
reference style and media integrity receive separate judgments.

Check generated geometry rather than trusting the helper name: stable atom/bond
IDs, unchanged upstream sites and selected axis, fixed explicit bond lengths and
deterministic reverse seeks. Record any unsupported or unverified claim. Export
adaptation may honor the production silent timing asset; it must not rewrite
generated geometry, motion or source bytes.
