# Reusable biological structures and mechanism motion

This is the next molecular capability slice after ordered backbone helpers.
Read molecular-reference.md, transcription-motion-supplement.md, current molecular
implementation/review/repair reports and assets reports. User requests much more
than schematic bead chains. Separate scientific representation, transcription
mechanism and Nucleus cinematic style; never let one artist's palette overwrite
another. Root assigns exact file ownership and serializes commits on amilibsam.

## Required evidence and design first

Independently inspect complete actual reference frames and ordered motion, not
only reports. Root saved nearly full transcription chronology at2fps in
data/animlib-expansion/transcription-late/{opening,complete}; view whole passages
and use browser for denser transitions. Protein Folding source140s and Nucleus
source239s still need fuller temporal inspection than initial research. Record
coverage precisely. No reference frame may become a production texture.

Write a narrow implementation design before code. Existing APIs: ordered sites,
explicit bonds/segments, sticks/beads/backbone, fixed-link articulated chain,
native tubes/solids/meshes/labels/views/outlines/clipping and host PDB/envelope
preparation. Prefer coherent missing capabilities over duplicating these.

## Scientific structure reuse

Extend host preparation to preserve useful real molecular identity and explicit
connectivity/chain-break data. Reuse small verified CC0 deposited structure1CRN
or another permitted source with precise accession/model/units/selection. Atomic
sticks, residue beads and surface must share the same structure and conformer;
do not substitute unrelated envelopes. TER/missing-segment/alternate-conformer
semantics must prevent invented bridges. Bond provenance must distinguish explicit
deposited/template connectivity from any declared geometric inference. Do not
claim an atomic bond graph from simple sequential site order. Prefer documented
existing parser/tool library offline when it saves substantial reliable work;
verify version/license and bound input/output. No scene VM parser dependency.

Use native prepared assets for large static endpoints so scripts remain small.
Provide stable residue/atom anchors and colors for representation changes and
local annotations. If a schematic unfolded-to-folded path uses a deposited
endpoint, derive and verify that endpoint rather than inventing a different fold;
state that motion is illustrative, not a physical folding trajectory. Existing
link-preserving kinematics should be reused and independently tested.

## Nucleic mechanism helpers

Observed missing reuse boundary: curved paired DNA/RNA backbones with ordered
base IDs, explicit complementary pairs, local unwinding window, growing transcript,
and semantic triplets/ends. Prefer a pure bounded factory returning native meshes
and anchor metadata, using explicit absolute-time phase data. Keep topology and
element count controlled; do not author one scene object per small polygon.
Base positions/orientations follow transported curve frames. Distinguish schematic
shapes/colors from chemical atomic geometry. Validate sequence alphabet/direction,
pairing choices and budgets. Be explicit about which biological convention is
encoded; cite primary sources for nontrivial scientific claims.

Create one original close-view mechanism proof: paired→unpaired window, persistent
template, incoming nucleotide/short transcript, translucent active machinery with
visible channel, local labels. Reuse licensed/prepared organic assets where
possible; no generic sphere masquerading as a ribosome-fidelity pass. A separate
environment/lighting slice may follow if renderer gaps remain. Keep static
prepared geometry cached and changing geometry within current reactive budgets.

## Verification and handoff

Meaningful regressions for IDs, sequence/pairing, breaks, finite transported frames,
invalid/sparse inputs, shared endpoint correspondence, budget rejection and reverse
seeks. Public host/QuickJS integration when needed must be serialized with current
owners. Native5–8s proof first, both aspect ratios, then independent evaluator.
Actual source and output motion comparisons determine subsequent work. Record
counts/timings/payload size and scientific/fidelity limitations. Do not assert
nearly identical quality from one good still or from tests alone.
