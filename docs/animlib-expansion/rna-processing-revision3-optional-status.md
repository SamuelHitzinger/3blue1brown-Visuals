# Optional textured pore capability

Work under `shared/animlib/fixtures/biological/rna-processing-revision3` and `data/animlib-expansion/rna-processing-revision3` is preserved as an unfinished optional asset capability. It contains original procedural membrane/contact colors, real lumen walls and rounded orange pore lobes. Its provenance describes baked illustrative illumination, not physical shadows. Native previews were made and inspected; no final films or independent approval are claimed.

The user subsequently prioritized 3Blue1Brown art/graphing style and source-derived motion techniques. Work stopped on this cellular rendering direction. The current delivery target is `rna-processing-3b1b-revision4`, with its own style contract and separate motion/visual-language gates. This change supersedes the earlier demand to match Nucleus cellular shading; it does not discard any original asset work or change the accepted helper semantics.
