# Biological motion follow-up design

2026-10-11. Follows independent review of the first native proofs. The deposited 1CRN assets and representation proof remain a separate scientific reuse demonstration. This follow-up adds illustrative motion; it will not claim a measured folding pathway or an authentic polymerase assembly.

## RNA arrival and emergence

Compatible addition to `NucleicTranscriptProps`: optional `incomingRotation: {axis:Vec3,angle:number}`. The axis is world-space and nonzero; angle is finite within ±4π. A free nucleotide rotates rigidly about its moving backbone anchor. Smooth arrival easing brings tip, tangent and normal to the exact docked frame before its first bond is formed. Default output remains unchanged. Regression verifies nonzero rotation, constant base reach, unit frames, unchanged formed anchors and reverse seek identity. This narrow addition is implemented; the subsequent emergence work below is still planned.

Do not silently change the existing fixed-snapshot RNA contract. Add explicit emergence parameters or a separate pure motion method that transports already formed sites from the template into an exit path. Its declared rest link lengths are those of the docked target chain. Starting from the currently active 3′ anchor, integrate backward along desired exit directions using those lengths, with a smooth age-dependent blend between template and exit directions. Thus earlier 5′ sites emerge while the current 3′ end remains at the active site. Formed anchors move continuously because emergence is intentional; existing fixed-snapshot callers retain their current behavior. The same resulting anchors drive plates, links, labels and triplet focus. No incoming nucleotide is included in a formed chain edge.

The proof shows relative machinery/DNA travel along the active window using retained whole-object transforms, then moves the camera closer to an already formed persistent triplet. A shell translation alone is insufficient: the frame relationship, exposed template, growing end and exit direction must remain readable. Update the style contract with exact stages and both-aspect framing before export. Avoid unnecessary environmental work until this mechanism passes review.

## Original illustrative peptide

Use an original sequence of 64–72 residues with substantial side-chain density. A bounded offline template table derives rigid residue coordinates and explicit intraresidue graph edges from the already pinned CCD ideal-coordinate records. Start with ALA/SER/VAL (approximately 5–7 heavy atoms each) to avoid disulfide and proline ring constraints. Preserve component atom names and authored stable atom/residue IDs, but use a clearly separate illustrative accession/identity namespace; this is not deposited 1CRN.

Construct a peptide backbone using internal coordinates. Each component's N–CA, CA–C lengths and N–CA–C angle come from its template. Explicit peptide link length and C–N–CA/CA–C–N angles are declared schematic constants. Phi/psi torsions vary; omega remains trans. Place each rigid component by the generated N/CA/C frame so its side-chain atoms and carbonyl oxygen travel with the same residue, retaining all intraresidue distances. Only explicit CCD and peptide edges are displayed. No sequential-atom inference and no smoothing of atomic XYZ independently.

Four local helical regions form progressively from an extended chain; held helical torsions persist while intervening loop torsions bring them into a compact bundle. A deterministic offline bounded search may choose loop torsions for a legible compact target, but sampling at runtime is analytic and history-free. The final surface must be prepared from the exact final generated atom coordinates. The proof labels the whole motion illustrative. Collision avoidance and an energy model are out of scope; obvious visual intersections remain an authoring/evaluation failure to fix, not an excuse to claim realistic dynamics.

Proposed pure helper: `peptidePose(spec, phi, psi)` returns stable atoms, CA anchors, explicit bonds and segment metadata. `spec` contains ordered residue IDs/component keys plus a compact reusable template dictionary. Arrays have exactly one phi/psi per residue. Sequence budget: 2–96 residues; dictionary up to 8 components, at most 24 heavy atoms/32 explicit edges per component; aggregate at most 1,536 atoms and 2,048 edges. Validate dense finite template coordinates, unique identities, template N/CA/C frames and all bond endpoints. The host preparation records provenance; the pure VM helper does no file or network work. Public naming and shared integration will be coordinated before editing shared files.

Existing `molecularBackboneGeometry` supplies sticks and beads from returned atoms/CA anchors. At 72 residues × approximately 6 atoms and radial quality 6–8, the dynamic stick mesh should remain roughly 7,000–14,000 vertices, split under existing per-mesh limits if necessary. Bounded native batches and scalar residue colors avoid hundreds of retained objects. The static final envelope remains an asset reference. Target scene-source payload: under 25 KB, using the small component dictionary once; do not embed prepared mesh arrays or increase VM/reactive caps.

## Gates before the next proof is accepted

Tests must preserve every displayed intraresidue and peptide bond through 101+ interior poses, stable atom/residue identities, continuous local frames, exact reverse seeks, and host/QuickJS agreement. Measure chain radius of gyration/end-to-end span and persistent local helix geometry to distinguish actual local coil formation and compaction from a mere camera move or contracting polyline. Verify final envelope origin/coordinates against the final pose. Render both native aspects and inspect ordered motion against the captured dense source segments; independent visual review is the acceptance gate. Keep the prior first-proof report intact as a historical slice, not a claim that this planned work already exists.
