## Comparison method

Six fresh production runs use the same neutral request within each A/B pair, `gpt-6-astra` high reasoning, interactive mode, supported subtitle timing, fresh lesson/editorial planning, authoring/validation and native WebGPU review with ordinary repairs. One scene is requested; the harness records any count violation and completes all planned scenes up to the same cap of three, rather than reporting a truncated lesson as complete. Maximum concurrency is two. Failures are retained.

All six refined runs completed with exactly one planned/published scene each. Every published source hash matches its approved native review. Internal validation errors, one recovered provider retry in A saddle, and first-pass native rejections remain in the logs; no failed attempt was silently replaced with manually corrected source. The original two enzyme preflights also completed and remain separate.

Both frozen trees received the same tested navigation runtime (`interaction`, `renderer`, `player`, `types` source and built files; 88 focused tests passed before copying). Their native workers use identical copied dist files. Initial package imports used by inspection resolved through the root package junction to live dist, however; live compiler/player files changed at **09:10:29 UTC**, during A enzyme and B saddle generation. Deadline setup and asset preparation differed; the native render copies did not change. Module caching prevents assigning an exact version to every operation from timestamps alone. Original outputs are retained without automatic model reruns. Remaining cases use fresh derived trees with local package bindings and matching package/native dist hashes. The [dependency audit](../data/prompt-preference-round2-20261011/runtime-drift.md) records this limitation and correction.

The retained author reference also describes the earlier paused-camera lock; it was deliberately left unchanged after the first pair launched. The newer navigation runtime supports paused inspection. Actual navigation must therefore be verified in the player, not inferred from that stale reference or a mode flag.

This is a small preference comparison, not a statistical benchmark. Random generation, different authored plans and normal repairs can affect outcomes. The imposed one-scene, 30–40-second probes test compact mechanisms and examples; they do not test full multi-scene overview-to-mechanism spatial planning. A passed native gate, extra geometry or lower annotation count alone does not establish better teaching. The choices support B's explicit central-observation guidance alongside shared simplicity, developed shapes, navigation and molecular-accuracy rules; the preferred older examples remain concrete visual references.
