# Faster Interdisciplinary Authoring Implementation Plan

> **For agentic workers:** Use subagent-driven-development for independently owned tasks; use executing-plans for the root's integration and proof work.

**Goal:** Reduce repeated animation authoring work while expanding tested scientific constructions and discoverable discipline guidance.

**Architecture:** Existing animlib scene/compiler/renderer, small pure state factories, bounded catalog/reference tools, existing quality gates. Additive contracts; complete reference remains accessible.

**Tech Stack:** TypeScript, QuickJS, Bun, Vitest, native WebGPU, existing Pi AgentRunner.

**Spec:** `docs/superpowers/specs/2026-10-14-interdisciplinary-authoring-design.md`.

## Global constraints

- Continue `codex/lecture-visual-catalog`; remote `visuals`, requested repository.
- Preserve unrelated `local-plugin/` and its planning file.
- No new renderer, numerical dependency, broad simulation engine, reduced review or unverified speed claim.
- Keep core/craft guidance; retrieve selected complete recipe text verbatim with explicit limits.
- Numerical/model availability does not constitute scientific or visual approval.

## Review focus

- Incomplete reference access during repair/review must fail clearly, not silently remove API knowledge.
- Cached compilation must invalidate when published model metadata changes and respect cancellation.
- Inputs with invalid dimensions, nonfinite values, overdraw or excessive work must fail before large allocations.
- Reverse seeks and mutable caller inputs must not corrupt related geometry and readouts.
- Catalog queries with noise, aliases, plural forms and overlapping discipline names need useful deterministic results within byte budgets.

## Tasks

- [x] Generation: add bounded reference service/tool, compact author context, validated-reference lecture completion, bounded validation reuse and metrics. Own backend agent files/tests. Red-green exact reconstruction, limits, propagation and cache tests; measure context reduction.
- [x] Scientific state: implement four small constructors with scene VM/core exports, types, documentation and four runnable recipes. Own library runtime/compiler/helper/test files and scientific docs. Red-green invariants, mutation/bounds and actual VM/seek tests.
- [x] Catalog: cache discovery indexes and ID maps, compact agent summaries, domain/readiness filters and interdisciplinary records. Own catalog shared metadata/docs/types and backend catalog service/tools/tests. Test retrieval/ranking/response bounds; benchmark representative 10,000-record search.
- [x] Proof/integration: root creates a geometry-led coupled-oscillator proof, numeric/seek checks and reproducible performance report; compiles new recipes and renders native frame evidence. Independent review inspects actual images and approved references.
- [x] Finish: resolve review findings; run relevant suites, typechecks and shipped builds; review complete diff; update evidence docs; commit/push only this continuation.
