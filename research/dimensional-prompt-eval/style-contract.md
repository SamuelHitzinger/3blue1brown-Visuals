## Visual acceptance

The same meaningful objects must persist through setup, operation and reading hold. Colors keep their semantic roles. Planar sine compression must preserve ordinate values while x coordinates move. Saddle sections must belong to the same actual surface. Enzyme docking must reveal a real cavity/contact relationship in a recognizably folded structure; an oblique disc, generic ellipsoid or flat cutout does not establish spatial fidelity. Idealized structures must be identified as schematic.

Judge representation choice, visible causal reasoning, spatial structure, readability and delivery separately. Inspect actual native rendered frames, including action interiors and endpoint holds. Independent review must distinguish sampled-image evidence from continuous playback. API use, element counts and compiler success alone cannot establish visual quality. Do not average a scientific or visual failure into a passing score.
