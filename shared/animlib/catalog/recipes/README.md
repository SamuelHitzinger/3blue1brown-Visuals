# Executable scientific construction seeds

These four small scene sources exercise the installed scientific-state helpers.
They are starting constructions, not independently approved complete explanatory
films. Preserve the concept's teaching sequence, labels, layout, interaction and
existing rendered review when adapting them.

| Seed | Shared calculation | Catalog route |
| --- | --- | --- |
| [Modal state](modal-state.js) | Supplied modes, positions and velocities | [Mechanical modes](../techniques/mechanical-modes.md) |
| [Conservative transport](conservative-transport.js) | Stocks and identified discrete flows | [Reaction/transport](../techniques/reaction-transport.md), [ecological flows](../techniques/ecological-flows.md) |
| [Complex interference](complex-interference.js) | Component amplitudes, resultant and squared magnitude | [Waves](../techniques/waves-interference.md), [signals](../techniques/signals-fourier.md) |
| [Event rates](event-rates.js) | Bounded kernel estimates from supplied event times | [Neural rates](../techniques/neural-event-rates.md) |

Read the [scientific-state contract](../../docs/scientific-state.md) for exact
signatures, limits, units, snapshots and scientific exclusions. No seed downloads
data, runs an arbitrary solver or changes renderer budgets. Construct reusable
state once and sample absolute time or explicit steps; repeated generation should
adapt these small tested calculations rather than regenerate numerical plumbing.
