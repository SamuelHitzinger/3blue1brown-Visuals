# Exact structured probe pair

From the repository root, with the current animlib build available:

```powershell
node_modules/.bin/bun.cmd backend/bench/realtime-pair-view.ts BASELINE_DIR CANDIDATE_DIR --brief=BRIEF_DIR
```

Open `http://127.0.0.1:5364/`. The optional brief directory must contain the
accepted shared perception run. No generation, TTS, audio substitution, source
repair or approval records are created. Both native engines use current dist.

The loader verifies source, prompt and image hashes, matching author user prompts
and settings, and equal compiled scene durations. System guidance may differ as
the experimental intervention. It verifies the supplied brief's exact inclusion
in the shared author prompt before attributing perception cost.

Play, pause, restart and seek operate both 1280×720 canvases using one silent
clock. A/B labels are initially shown; the reveal control displays baseline /
candidate identities and recorded model timings. Order is baseline first, not
randomized, so this display is not itself a blind evaluation protocol.

Provider timing and brief-plus-author sums exclude capture, ASR, compilation,
rendering and presentation. They establish neither ten-second complete readiness
nor scientific or visual quality. Browser playback must still be checked.
